# Sample recording

`x05` is one full overnight recording from the PhysioNet Apnea-ECG Database v1.0.0, copied unchanged (.dat ECG, .hea header, .qrs QRS annotations, .apn per-minute apnea labels). It belongs to a **test-split subject** (never used for training). It lets the demo app run the whole pipeline (raw ECG to diagnosis) without downloading the full database.

Source: Penzel T, Moody GB, Mark RG, Goldberger AL, Peter JH. The Apnea-ECG Database. Computers in Cardiology 2000;27:255-258. Goldberger AL et al., PhysioBank, PhysioToolkit, and PhysioNet, Circulation 2000. https://physionet.org/content/apnea-ecg/1.0.0/ (license: Open Data Commons Attribution License v1.0).
